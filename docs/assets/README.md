# README Visual Assets

The root README expects these visual assets:

```text
docs/assets/monde_lockup_v1.png
docs/assets/overview_dashboard_hero.png
docs/assets/chat_demo.gif
docs/assets/chat_rail.png
docs/assets/mons_overview.png
docs/assets/runs_overview_hero.png
```

Current roles:

- `monde_lockup_v1.png`: top README brand lockup.
- `overview_dashboard_hero.png`: primary visual hook and home dashboard section.
- `chat_demo.gif`: mon thread interaction demo.
- `chat_rail.png`: persistent chat rail and thread widget detail.
- `mons_overview.png`: Mons tab, actor metadata, permissions, and actions.
- `runs_overview_hero.png`: Runs and Review surface with terminal evidence.

Current dimensions:

```text
monde_lockup_v1.png          2190 x 749
overview_dashboard_hero.png  2385 x 1267
runs_overview_hero.png       2377 x 1346
mons_overview.png            1158 x 594
chat_rail.png                676 x 662
chat_demo.gif                800 x 1356
```

Keep assets optimized before committing. Prefer screenshots wide enough to
remain crisp at the README display width. The current dashboard and runs
screenshots are wide enough for full-width README display; the chat GIF and
chat rail image are intentionally used as supporting visuals.
